## 🎯 **Project Overview**

The Debt Relief project is an AI-powered financial tool that helps people understand and plan their debt payoff strategies. It consists of:

- **Frontend**: Web interfaces for users to input their debt information
- **Backend**: Python/Flask server that performs calculations
- **External APIs**: Integration with banking systems for realistic simulations
- **Multiple Interfaces**: Basic calculator, advanced medical debt simulator, questionnaire format

### Key Features:
- Calculate exact debt payoff timelines
- Show how much interest will be paid
- Provide multiple payoff strategies
- Handle complex medical debt scenarios
- Integrate with real banking systems
- Export results as PDF or CSV
